02 / THE IDEA

Ask the planning objective.

Prediction and control need
different things from an image.

COSTGRAD scores each visual token by how strongly it affects the planning cost. A single gradient probe chooses the tokens; the planner then searches over actions using that smaller representation. The predictor stays fixed: no retraining is required.

01

Probe the goal

Encode the observation and goal. Predict one step with a zero-action probe and measure the latent distance to the goal.

Lprobe = ‖p(z, 0) − zgoal‖²
02

Score the tokens

Backpropagate the cost to the input tokens. Retain the K positions with the largest gradient norms.

sj = ‖∂Lprobe / ∂zj‖₂
03

Plan on the subset

Run the full CEM action search on those positions. Keep the subset fixed within a planning step; select again when replanning.

S = TopK(s) → sparse rollouts

04 / UNDERSTANDING SPARSE PLANNING

Token choice changes
the planning problem.

A token can matter for planning through its own prediction or by supplying context for predictions elsewhere. COSTGRAD uses sensitivity to the goal-reaching cost to identify that influence.

Removing tokens also changes the predictor’s computation. Sparse planning therefore depends on both the selected state information and the resulting action-conditioned rollouts.

Scope and future work +

The performance comparisons above use AdaLN-conditioned predictors, DINOv2 visual features, CEM planning, and four simulated continuous-control tasks. Generality across other conditioning mechanisms, including FiLM and cross-attention, and evaluation on physical systems remain future work.

The displayed MetaWorld demo uses our retrained Reach predictor. The released-checkpoint control also evaluates Reach, using the public checkpoint. The one-step gradient probe selects tokens; action search still evaluates full-horizon rollouts.
